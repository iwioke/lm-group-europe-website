# Загрузка сайта LM Group на hoster.by

Сайт статический (HTML + CSS + видео), никакой БД, PHP и Node на хостинге не нужно.
Подойдёт самый простой тариф виртуального хостинга.

---

## 1. Собрать архив

```bash
cd /Users/iwioke/CascadeProjects/lm-group-landing
npm run deploy:zip
```

Появится `deploy.zip` (~6.2 МБ). Внутри ровно то, что нужно на сервере:

```
index.html
.htaccess          ← сжатие, кэш, редирект на HTTPS
robots.txt
assets/styles.css
assets/favicon.svg
assets/lm-mark.svg
assets/lm-wordmark.svg
assets/lm-group-logo.png
assets/transport-new.mp4
assets/customs-new.mp4
assets/warehouse.mp4
assets/groupage.mp4
```

> **Важно:** `node_modules`, `src/`, `package.json`, `Dockerfile` на хостинг **не нужны** —
> CSS уже скомпилирован в `assets/styles.css`. Скрипт `deploy:zip` их и не кладёт.

## 2. Куда заливать

Зайдите в личный кабинет hoster.by → раздел **Хостинг** → **Панель управления**
(hoster.by использует ISPmanager).

Корневая папка сайта обычно одна из этих:

- `/var/www/<логин>/data/www/<домен>/`
- `~/www/<домен>/`
- `public_html/`

Точный путь виден в панели: **WWW → WWW-домены → ваш домен → «Корневая директория»**.
Ориентир — это та папка, где лежит дефолтный `index.html` от хостера.

---

## 3. Способ А — через файловый менеджер (проще)

1. В панели откройте **Менеджер файлов**.
2. Перейдите в корневую папку домена.
3. **Удалите** заглушку хостера (`index.html`, `index.php`, папку `cgi-bin` не трогайте).
4. Нажмите **Закачать** и выберите `deploy.zip`.
5. Выделите загруженный `deploy.zip` → кнопка **Извлечь** (Extract).
6. Убедитесь, что файлы легли **в корень**, а не в подпапку `deploy/`.
   Правильно: `<корень>/index.html` и `<корень>/assets/…`
7. Удалите сам `deploy.zip` с сервера.

> Если после распаковки `.htaccess` не видно — включите показ скрытых файлов
> (в ISPmanager: **Настройки → Показывать скрытые файлы**).

---

## 4. Способ Б — через FTP (FileZilla)

Данные FTP: панель hoster.by → **FTP-пользователи**.

| Поле  | Значение                        |
|-------|---------------------------------|
| Хост  | `ftp.<ваш-домен>` или IP сервера |
| Порт  | `21`                            |
| Логин | из панели                        |
| Пароль| из панели                        |

1. Подключитесь, перейдите в корневую папку домена.
2. Распакуйте `deploy.zip` локально.
3. Перетащите **содержимое** папки (не саму папку) на сервер.
4. В FileZilla включите показ скрытых файлов:
   **Сервер → Принудительно отображать скрытые файлы**, иначе `.htaccess` не зальётся.

Видео ~6 МБ суммарно — по FTP заливается медленнее, чем zip'ом. Способ А быстрее.

## 5. SSL и HTTPS

1. В панели: **WWW-домены → ваш домен → SSL-сертификаты → Let's Encrypt** (бесплатный).
2. Дождитесь выпуска (обычно несколько минут).
3. Проверьте, что `https://ваш-домен` открывается без предупреждений.
4. **Только после этого** включите принудительный редирект: откройте `.htaccess`
   и раскомментируйте последний блок (уберите `#`):

```apache
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteCond %{HTTPS} off
  RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
</IfModule>
```

> Если включить редирект **до** выпуска сертификата — сайт уйдёт в бесконечный
> редирект и станет недоступен.

- [ ] Логотип в шапке на месте, favicon в вкладке браузера

## 7. Обновление сайта в будущем

После правок в `index.html` или `src/input.css`:

```bash
npm run deploy:zip
```

и залейте заново (шаг 3). Достаточно перезаписать `index.html` и `assets/styles.css` —
видео и картинки менять не нужно, если они не правились.

> **Важно про кэш:** после изменения CSS поднимите номер версии в `index.html`:
> `assets/styles.css?v=21` → `?v=22`. Иначе у посетителей останется старый CSS из кэша браузера.
